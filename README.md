# make-knowledge-cards

一个开源 Skill：把粘贴的文章或本地 Markdown / TXT 文件提炼成 **5~8 张结构化知识卡片**。每张卡片只讲一个知识点，且只使用原文中的信息。

## 1. 项目解决什么问题

读完一篇文章后，手工整理要点费时且容易变成原文摘抄。这个项目把提炼工作交给 Agent：自动找出文章中真正重要的知识点，改写成密度高、可复习的卡片，同时严格约束"不编造、不重复、不硬凑数量"。它适合把教程、笔记、长文快速转成可反复回顾的学习材料。

## 2. 主要功能

- **输入**：直接粘贴的文章正文，或本地 `.md` / `.markdown` / `.txt` 文件（给出路径即可，Skill 会自行读取）。
- **输出**：5~8 张 Markdown 知识卡片，每张包含 **标题、核心知识、简明解释、例子或自测问题** 四个字段。
- **提取原则**：只收录核心概念、原理、机制、方法、结论或重要区分；一张卡片只讲一个知识点；删除重复表述。
- **诚实约束**：不补充原文没有的信息；信息不足时按实际知识点数量输出并说明，不为凑 5~8 张而拆分、复述或编造。
- **数量与语言**：数量由内容决定（超过 8 个按重要性取前 8 个）；卡片语言默认与原文一致。
- **暂不支持**：网页抓取、PDF 解析、Anki 导入、图形界面操作。

## 3. 安装方法

本项目是 Skill 源码目录，不包含安装脚本或包管理器配置。安装即把 `skills/make-knowledge-cards` 目录复制到目标 Agent 的 skills 目录：

```bash
# Codex：复制到 skills 目录（CODEX_HOME 未设置时用默认路径）
cp -r skills/make-knowledge-cards "$HOME/.codex/skills/"

# 若使用项目级目录，改为：
# cp -r skills/make-knowledge-cards .workbuddy/skills/
```

目录结构必须保持为：

```
make-knowledge-cards/
├── SKILL.md              # Skill 指令与工作流（必需）
└── agents/openai.yaml    # UI 元数据：显示名、简介、默认提示词
```

依赖：无。该 Skill 只提供文本指令，不需要额外脚本或第三方库。

## 4. 使用方法

安装后，在 Agent 对话中用 `$make-knowledge-cards` 触发，并给出正文或文件路径。

**示例输入（粘贴正文）**

```
用 $make-knowledge-cards 把下面这篇文章整理成知识卡片：
（此处粘贴文章正文）
```

**示例输入（本地文件）**

```
用 $make-knowledge-cards 处理 ./notes/article.md
```

Skill 会读取全文 → 筛选知识点 → 一卡一点并去重 → 撰写卡片 → 自检后输出。无需追问主题或偏好。

## 5. 输入输出示例

**输入原文（节选）**

> TCP 是面向连接的可靠传输协议，发送数据前必须先通过三次握手建立连接。采用三次而非两次握手，是为了防止已失效的连接请求突然到达服务器而造成错误。

**输出卡片**

```markdown
## 1. TCP 通过三次握手建立连接

- **核心知识**：TCP 是面向连接的可靠传输协议，发送数据前通信双方必须先通过三次握手建立连接。
- **简明解释**：原文指出，TCP 在发送数据前必须先建立连接，这一建立连接的过程称为三次握手。
- **自测问题**：根据原文，TCP 在发送数据前必须先完成什么过程？

## 2. 三次握手防止已失效的连接请求造成错误

- **核心知识**：采用三次而非两次握手，核心原因是防止已失效的连接请求突然到达服务器而造成错误。
- **简明解释**：原文指出，延迟的旧 SYN 到达服务器时，若只握手一次就会建立无效连接；第三次握手的 ACK 确认避免了这一点。
- **例子**：客户端第一个 SYN 在网络中延迟，客户端超时重发并完成、关闭连接后，那个滞留的旧 SYN 才到达服务器。
```

**信息不足时的输出**：原文独立知识点不足 5 个时，只输出实际可提炼的卡片，并在末尾附一行说明：

```
原文可提炼的独立知识点不足 5 个。
```

## 开发与验证

Skill 由官方 skill-creator 的 `init_skill.py` 初始化，可用其 `quick_validate.py` 校验结构：

```bash
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
```

## 网页应用（本地规则版）

`web/` 是一个纯前端网页应用，可直接用浏览器打开 `web/index.html`，或在该目录运行任意静态文件服务器访问。

- 支持粘贴正文，或选择 / 拖入 `.md` / `.markdown` / `.txt` 文件（最大 2 MB）。
- 在浏览器本地按原文句子和关键词抽取并去重，输出带四个字段的卡片；不足 5 个知识点时按实际数量输出并说明。
- 可复制为 Markdown 或下载 `knowledge-cards.md`。
- 不联网、不上传内容、不需要账号或 API Key。
- 局限：这是规则版，不做语义理解与改写，卡片质量不如配合大模型使用的 Skill；不会补充原文没有的信息。

文件：`web/index.html`、`web/styles.css`、`web/app.js`（无构建步骤、无第三方依赖）。
